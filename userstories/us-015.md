# US-015: Báo cáo quản trị

## User Story

As an **Admin**, I want **xem dashboard tổng quan hệ thống (user, trận, revenue, analytics)**, so that **tôi giám sát hoạt động và ra quyết định kinh doanh dựa trên data**.

## Context

Admin dashboard: số user, số trận, revenue (commission + premium), slot occupancy rate, analytics hành vi. Aggregated data tối ưu truy vấn. Tích hợp Google Analytics/Firebase cho product analytics.

## Acceptance Criteria

### AC-001 — Admin xem dashboard tổng quan

- **Type:** happy-path
- **Covers:** FR-sport-matching-020

```gherkin
Given Admin đăng nhập với role Admin
When Admin mở dashboard
Then Hiện tổng quan: số Player active (MAU), số Partner, số trận/tháng, revenue (commission + premium), slot occupancy rate peak hours
```

### AC-002 — Xem analytics hành vi

- **Type:** happy-path
- **Covers:** FR-sport-matching-020

```gherkin
Given Admin muốn phân tích hành vi Player
When Admin chọn tab Analytics
Then Hiện data từ Google Analytics/Firebase: retention, time-to-match, top môn, top khu vực, conversion funnel
```

### AC-003 — Filter theo thời gian

- **Type:** happy-path
- **Covers:** FR-sport-matching-020

```gherkin
Given Admin đang xem dashboard
When Admin chọn filter "Tháng 6/2026"
Then Tất cả metrics cập nhật theo tháng đã chọn
```

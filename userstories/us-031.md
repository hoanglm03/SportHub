# US-031: Onboarding chủ sân tự động

## User Story

Là một **Chủ sân (Partner)**, tôi muốn **đăng ký làm đối tác ngay trên app** để **bắt đầu đăng sân và nhận booking nhanh chóng**.

## Acceptance Criteria

### AC-001: Hoàn thành 3 bước
**Given** User nhấn "Đăng ký chủ sân"
**When** nhập thông tin + upload CMND + tick điều khoản + submit
**Then** status = pending, hiện "Đang xét duyệt 🟡", Admin nhận noti

### AC-002: Thiếu giấy tờ
**Given** User chỉ nhập thông tin, chưa upload CMND
**When** nhấn Submit
**Then** E-019 "Vui lòng upload đầy đủ CMND/CCCD và giấy phép kinh doanh"

### AC-003: Chưa tick điều khoản
**Given** User chưa tick checkbox điều khoản
**When** nhấn Submit
**Then** validate error "Vui lòng đồng ý Điều khoản sử dụng"

### AC-004: Admin duyệt
**Given** Partner pending
**When** Admin approve
**Then** Partner role activated, nhận noti "Chúc mừng! Bạn đã được duyệt", redirect venue-manage

### AC-005: Admin từ chối
**Given** Partner pending
**When** Admin từ chối + lý do "Ảnh CMND mờ"
**Then** Partner nhận noti + lý do, mở lại form sửa + submit lại

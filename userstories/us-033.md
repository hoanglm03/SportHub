# US-033: Admin dashboard doanh thu & moderate

## User Story

Là một **Admin**, tôi muốn **xem dashboard doanh thu và moderate đánh giá** để **theo dõi hiệu quả kinh doanh và kiểm soát nội dung**.

## Linked Requirements

| FR | Mô tả |
|----|-------|
| FR-sport-matching-045 | Dashboard doanh thu |
| FR-sport-matching-046 | Moderate đánh giá |

## Acceptance Criteria

### AC-001: Dashboard KPI
**Given** Admin mở admin-dashboard
**When** dashboard load
**Then** hiện: users active, matches tháng, venues active, revenue tháng, slot occupancy rate. Filter theo khoảng thời gian

### AC-002: Moderate đánh giá
**Given** 5 đánh giá bị report
**When** Admin vào Moderate > xem đánh giá flagged
**Then** xem nội dung + context. Nút Ẩn/Xóa/Bỏ qua. Cảnh báo user nếu cần

### AC-003: Xử lý report kết quả conflict
**Given** 2 Player report kết quả conflict (cả 2 claim thắng)
**When** Admin vào Tranh chấp
**Then** xem chi tiết trận + report 2 bên. Quyết định kết quả hoặc void

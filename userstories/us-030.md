# US-030: Admin quản lý user

## User Story

Là một **Admin**, tôi muốn **quản lý tài khoản user (Player/Partner)** để **xử lý vi phạm và hỗ trợ vận hành**.

## Linked Requirements

| FR | Mô tả |
|----|-------|
| FR-sport-matching-042 | Quản lý user |

## Acceptance Criteria

### AC-001: Xem danh sách user
**Given** Admin mở Quản lý User
**When** danh sách load
**Then** hiện tất cả user, search theo tên/email, filter theo role (Player/Partner) và status (active/locked)

### AC-002: Khóa user vi phạm
**Given** Admin tìm user "spammer123"
**When** nhấn Tạm khóa + ghi lý do
**Then** user bị lock, không đăng nhập được, booking pending bị hủy

### AC-003: Mở khóa user
**Given** user đã bị lock
**When** Admin nhấn Mở khóa
**Then** user đăng nhập lại được bình thường

### AC-004: Unauthorized — Partner truy cập sân người khác
**Given** Partner A đăng nhập
**When** cố truy cập venue-manage của Partner B
**Then** chỉ thấy sân của mình, không access data Partner khác. Covers: BR-sport-matching-025

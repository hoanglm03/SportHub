# US-016: Report kết quả trận

## User Story

As a **Player**, I want **tự report kết quả trận đấu (Thắng/Thua/Hòa) sau khi chơi xong**, so that **hệ thống ghi nhận chính xác thống kê win/loss của tôi**.

## Context

Sau trận hoàn thành, cả 2 Player tự report kết quả. Nếu 2 bên report khớp → ghi nhận. Nếu conflict (cả 2 claim thắng) → flag cho Admin review. Kết quả dùng cho thống kê win/loss (FR-012) và ELO auto-adjust (FR-014).

## Linked Requirements

| FR | Priority | Notes |
|----|----------|-------|
| FR-sport-matching-021 | P0 | Report kết quả trận (self-report, conflict → Admin) |
| FR-sport-matching-012 | P0 | Kết quả dùng cho thống kê win/loss |

## Acceptance Criteria

### AC-001 — Report kết quả thành công (khớp)

- **Type:** happy-path
- **Covers:** FR-sport-matching-021

```gherkin
Given Trận đấu đã hoàn thành
When Cả 2 Player report cùng kết quả (vd: Player A report Thắng, Player B report Thua)
Then System ghi nhận kết quả, cập nhật thống kê win/loss cho cả 2
```

### AC-002 — Report conflict (cả 2 claim thắng)

- **Type:** error-path
- **Covers:** FR-sport-matching-021

```gherkin
Given Trận đấu đã hoàn thành
When Cả 2 Player report Thắng (conflict)
Then System flag trận cho Admin review, hiện thông báo "Kết quả đang chờ xác nhận từ quản trị viên" cho cả 2
```

### AC-003 — Report Hòa

- **Type:** happy-path
- **Covers:** FR-sport-matching-021

```gherkin
Given Trận đấu đã hoàn thành
When Cả 2 Player report Hòa
Then System ghi nhận Hòa, thống kê không thay đổi win/loss, chỉ tăng số trận đã chơi
```

### AC-004 — Nhắc report sau 12h

- **Type:** state/ui
- **Covers:** FR-sport-matching-021

```gherkin
Given Player A đã report kết quả, Player B chưa report
When 12 giờ trôi qua
Then System gửi push notification nhắc Player B "Hãy report kết quả trận đấu"
```

### AC-004b — Auto-accept sau 24h

- **Type:** state/ui
- **Covers:** FR-sport-matching-021

```gherkin
Given Player A đã report kết quả, Player B chưa report
When 24 giờ trôi qua
Then System lấy kết quả Player A làm mặc định, ghi nhận vào thống kê win/loss, thông báo cả 2
```

### AC-005 — Admin resolve conflict

- **Type:** happy-path
- **Covers:** FR-sport-matching-021

```gherkin
Given Trận bị flag conflict
When Admin review và chọn kết quả chính xác
Then System cập nhật win/loss theo quyết định Admin, thông báo cả 2 Player
```

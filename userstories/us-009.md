# US-009: Auto-adjust trình độ

## User Story

As a **System**, I want **tự động điều chỉnh trình độ Player dựa trên ELO rating**, so that **matching ghép chính xác hơn và Player fake trình độ bị phát hiện**.

## Context

ELO-based: Player cấp Trung bình liên tục thắng/nhận rating cao từ đối thủ cùng bậc dẫn tới tự động chuyển sang Nâng cao (ngược lại tương tự). Cập nhật hồ sơ + Matching Score.

## Acceptance Criteria

### AC-001 — Tự động tăng bậc trình độ

- **Type:** happy-path
- **Covers:** FR-sport-matching-014

```gherkin
Given Player cấp Trung bình liên tục thắng và nhận rating cao từ đối thủ cùng bậc (vượt ngưỡng ELO)
When System chạy ELO check sau mỗi trận
Then Player tự động chuyển sang cấp Nâng cao, profile cập nhật, Matching Score điều chỉnh
```

### AC-002 — Tự động giảm bậc trình độ

- **Type:** happy-path
- **Covers:** FR-sport-matching-014

```gherkin
Given Player cấp Nâng cao liên tục thua và nhận rating thấp (dưới ngưỡng ELO)
When System chạy ELO check
Then Player tự động giảm về cấp Trung bình, profile cập nhật
```

### AC-003 — Player mới chưa đủ data

- **Type:** state/ui
- **Covers:** FR-sport-matching-014

```gherkin
Given Player mới chơi < 5 trận (chưa đủ data ELO)
When System check auto-adjust
Then Giữ nguyên trình độ tự khai báo, không adjust
```
